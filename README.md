# Dual Grid Mapping Method 2D
Implementation of the DGMM for 2D heterogeneous domains from the manuscript: DJ Oliver, IW Turner, and EJ Carr
"A two-dimensional dual-grid mapping method to simulate contaminant transport in heterogeneous groundwater systems"
https://dx.doi.org/10.1016/j.compgeo.2024.106999

Requires GMSH if generating a new mesh.
Place gmsh.exe in the base directory containing run.m before running the code.
Otherwise, use the provided mesh.m.
